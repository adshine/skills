Replace these with the brand's own principles. Each one should help someone choose between two reasonable options.

## Clear before clever

People come to get something done. Say what will happen in plain words and show the next step.

## One main action

Every view has one primary button. Everything else is quieter.

## Readable everywhere

Text meets contrast targets in light and dark, at 200% zoom and in bright sunlight on a phone.

## Plain HTML first

Use a native element before adding script: a real `button`, a real `label`, a real `dialog`. Native elements bring keyboard support and screen reader support for free, and they keep working when a page builder strips out JavaScript.

## Consistent beats new

Reuse an existing pattern before inventing one. A new pattern needs evidence that the old one fails.
