Components are the building blocks. They follow the [foundations](/foundations/color) and get combined into [patterns](/patterns/overview). Start from the closest component instead of building a new one.

Each component is a set of CSS classes in `components.css`. Classes use a short block name with modifiers after two dashes, like `btn btn--outline`, and parts after two underscores, like `card__title`.
