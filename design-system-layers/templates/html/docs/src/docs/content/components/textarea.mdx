## When to use

- For answers that may run to more than one line: messages, notes, feedback, project briefs.
- When people need room to explain in their own words.

## When not to use

- **For short, single values.** Use a [text field](/components/text-field) for names, emails and titles.
- **For formatted content.** A textarea is plain text only. Use a rich text editor if people need headings, links or lists.
- **For answers you can predict.** Offer [radio buttons](/components/radio) or [checkboxes](/components/checkbox), then a textarea for "anything else".

## Size

Set `rows` to match the answer you expect: three or four rows for a short message, six to eight for a brief. A box that is too small tells people to write less. People can drag the corner to make it taller; it never grows sideways.

## Content

- Label says what to write about: "Tell us about your project", not "Comments".
- If there is a length limit, say it in the helper text before people start, not only as an error.
- Placeholders can suggest what to cover, but never hold instructions people need.

## Markup

```html
<div class="field">
  <label class="label" for="message">Message</label>
  <textarea class="textarea" id="message" name="message" rows="4"
            aria-describedby="message-hint"></textarea>
  <p class="field-hint" id="message-hint">A few sentences is enough.</p>
</div>
```

| Class | What it does |
| --- | --- |
| `textarea` | Multi-line field matching text fields. Resizes vertically. |
| `field`, `label`, `label__optional`, `field-hint`, `field-error` | Same as [text field](/components/text-field) |

## Length limits

Use `maxlength` to stop typing at a hard limit, and say the limit in the hint so it is not a surprise:

```html
<textarea class="textarea" id="bio" maxlength="300" aria-describedby="bio-hint"></textarea>
<p class="field-hint" id="bio-hint">Up to 300 characters.</p>
```

## WordPress and Webflow

- **WordPress:** give the form plugin's paragraph or message field the class `textarea`.
- **Webflow:** give a Text Area element the class `textarea` and leave its Webflow styles empty.

## Styling

Reads `--input`, `--ring`, `--destructive` and `--radius`, like every field. Minimum height is 4rem; set `rows` for more.

## Keyboard

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Moves focus into the textarea |
| <kbd>Enter</kbd> | Adds a new line (it does not submit the form) |
| <kbd>Shift</kbd> + <kbd>Tab</kbd> | Moves focus to the previous field |

## Checklist

- Every textarea has a visible `label` tied to it with `for` and `id`.
- Helper and error text are linked with `aria-describedby`.
- Errors set `aria-invalid="true"` and say what to do next.
- Length limits are stated up front in text, not only enforced.
- Never trap focus or submit on <kbd>Enter</kbd>; people need new lines.
