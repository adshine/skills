## The rule: one value

Every corner on the site is derived from a single variable, `--radius`, set in `brand.css`. Components multiply it:

| Step | CSS value | Used by |
| --- | --- | --- |
| Small | `calc(var(--radius) * 0.6)` | The selected tab inside a tab rail |
| Medium | `calc(var(--radius) * 0.8)` | Buttons, text fields, selects, text areas, skeletons |
| Default | `var(--radius)` | Dialogs, toasts, alerts |
| Large | `calc(var(--radius) * 1.4)` | Cards |
| Full | `999px` or `50%` | Badges, switches, avatars |

Change `--radius` and the whole site changes shape together: `0.25rem` reads sharp and technical, `0.625rem` (the default) reads friendly and neutral, `1rem` reads soft.

```css
/* brand.css */
:root {
  --radius: 0.625rem;
}
```

## Nesting

When one rounded shape sits inside another, the inner corner is smaller than the outer one, so the gap between them looks even. A tab inside the tab rail uses Small inside Medium; a button inside a card uses Medium inside Large.

## Using it in your own CSS

When you build something new, use the same steps instead of a fixed value:

```css
.promo-banner {
  border-radius: calc(var(--radius) * 1.4);
}
```

Never write a fixed corner like `border-radius: 6px`. It will not change when the brand does.
