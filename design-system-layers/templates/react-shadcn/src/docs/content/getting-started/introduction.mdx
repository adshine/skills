This design system is the shared language for building our products. It has three layers, and each one does a different job:

| Layer | Answers | Examples |
| --- | --- | --- |
| [Foundations](/foundations/color) | Why is it this way? | Color, type, shape, spacing, motion |
| [Components](/components/overview) | What is this block and what states does it have? | Button, text field, dialog |
| [Patterns](/patterns/overview) | How does it work for people, in context? | Booking, forms, empty and error states |

When a question comes up, name the layer first. A spacing debate is a foundation question; a widget's states are a component question; how a flow behaves is a pattern question. Most stuck discussions are two layers talking past each other.

## How to use these docs

- **Building a screen?** Check [Patterns](/patterns/overview) first. If a pattern exists, follow it.
- **Need a part?** Find it in [Components](/components/overview). Every page has live examples, code to copy and accessibility notes.
- **Something missing?** See [Contributing](/resources/contributing).
