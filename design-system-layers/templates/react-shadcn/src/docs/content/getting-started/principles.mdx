Replace these with the product's own principles. Each one should help someone choose between two reasonable options.

## Clear before clever

People come to get something done. Say what will happen in plain words and show the next step.

## One main action

Every view has one primary action. Everything else is quieter.

## Readable everywhere

Text meets contrast targets in light and dark, at 200% zoom and in bright sunlight on a phone.

## Consistent beats new

Reuse an existing pattern before inventing one. A new pattern needs evidence that the old one fails.
