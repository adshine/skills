## When to use

- To pick any number of options from a list, including none.
- For a single opt-in that takes effect when the form is submitted, like agreeing to terms.

## When not to use

- **For one choice from several.** Use a [radio group](/components/radio-group).
- **For a setting that applies right away.** Use a [switch](/components/switch).
- **For long lists.** Over about ten options, consider a searchable multi-select.

Use the indeterminate state only on a parent checkbox whose children are partly selected, like "Select all" in a table. It shows a minus sign, and screen readers announce it as "mixed".

## Content

- Write labels so that checked means "yes": "Remember this device", not "Do not remember this device".
- Keep labels short and in sentence case, with no punctuation at the end.
- Make the label clickable (the `Label` does this) so the target is bigger than the box.
- Never preselect a checkbox that signs people up for marketing or payment.

## Controlled

```tsx
const [agreed, setAgreed] = React.useState(false)

<div className="flex items-center gap-2">
  <Checkbox
    id="terms"
    checked={agreed}
    onCheckedChange={(v) => setAgreed(v === true)}
  />
  <Label htmlFor="terms">I agree to the terms of service</Label>
</div>
<Button disabled={!agreed}>Create account</Button>
```

## Select all

```tsx
const all = items.every((i) => selected.includes(i.id))
const some = items.some((i) => selected.includes(i.id))

<Checkbox

  checked={all ? true : some ? "indeterminate" : false}
```

## Keyboard

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Moves focus to the checkbox |
| <kbd>Space</kbd> | Checks or unchecks it |

## Checklist

- Every checkbox has a label linked with `htmlFor` and `id`, or an `aria-label` when there is no visible text, like in a table row.
- Groups use `fieldset` and `legend` so the question is read before each option.
- The indeterminate state is announced as "mixed" by screen readers.
- The checked state is shown by a check mark, not by color alone.
- Errors set `aria-invalid` and are explained in visible text.
- The clickable area (box plus label) is at least 44 by 44 px on touch screens.
