## When to use

- To choose one option from about five to fifteen known choices.
- When space is tight and the current choice matters more than comparing every option.

## When not to use

- **For two to five options.** Use a [radio group](/components/radio-group) so every choice is visible without opening anything.
- **For long lists people search through,** like countries or customers. Use a searchable combobox.
- **For actions.** A select changes a value. To run a command, use a dropdown menu or a [button](/components/button).
- **For several choices at once.** Use [checkboxes](/components/checkbox).

## Content

- Order options in a way people expect: by frequency, by size, or alphabetically when nothing else fits.
- Keep option labels short and parallel, starting with the word that differs: "Daily", "Weekly", "Monthly".
- Placeholders read as an instruction: "Choose a plan". If one option is a safe default, preselect it instead.
- Never put a "Select..." option inside the list as a real value.

## Controlled with a form

```tsx
const [plan, setPlan] = React.useState("")

<Label htmlFor="plan">Plan</Label>
<Select value={plan} onValueChange={setPlan} name="plan" required>
  <SelectTrigger id="plan" className="w-full" aria-describedby="plan-help">
    <SelectValue placeholder="Choose a plan" />
  </SelectTrigger>
  <SelectContent>
    <SelectItem value="basic">Basic</SelectItem>
    <SelectItem value="team">Team</SelectItem>
    <SelectItem value="enterprise">Enterprise</SelectItem>
  </SelectContent>
</Select>
<p id="plan-help" className="text-sm text-muted-foreground">You can change this at any time.</p>
```

## Keyboard

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Moves focus to the trigger |
| <kbd>Enter</kbd>, <kbd>Space</kbd> or <kbd>Arrow down</kbd> | Opens the list with the selected option focused |
| <kbd>Arrow up</kbd> or <kbd>Arrow down</kbd> | Moves between options |
| <kbd>Home</kbd> or <kbd>End</kbd> | Jumps to the first or last option |
| Typing letters | Jumps to the first option that starts with them |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | Picks the focused option and closes the list |
| <kbd>Esc</kbd> | Closes the list without changing the value |

## Checklist

- The trigger has an accessible name, from a `Label` linked by `id` or from `aria-label`.
- Radix gives the trigger the `combobox` role and the options the `option` role, and announces the selected value.
- Focus returns to the trigger when the list closes.
- Disabled options stay in the list so people can see they exist; explain why if it is not obvious.
- Errors set `aria-invalid` and are described in visible text linked with `aria-describedby`.
- The focus ring uses `--ring` and meets 3:1 contrast against the page.
