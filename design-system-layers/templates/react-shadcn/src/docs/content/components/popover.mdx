## When to use

- To show a few related settings or filters next to the control they affect.
- To explain a term or number with more than a sentence, including a link.
- To host a picker, like the [date picker](/components/calendar), that should not take over the page.

## When not to use

- **For a one-line hint on hover.** Use a [tooltip](/components/tooltip).
- **For a list of actions.** Use a [menu](/components/dropdown-menu); it has the right keyboard behavior.
- **When people must answer before going on.** Use a [dialog](/components/dialog).
- **For long forms.** If it needs scrolling, it belongs on a page or in a dialog.

## Information popover

A small icon button can open a short explanation. Unlike a tooltip, it stays open until people close it and can hold links.

## Content

- Lead with a short title that matches the trigger label.
- Keep it to what fits without scrolling: a few fields, a short explanation or a picker.
- Apply changes as people make them, or add one clear button such as "Apply filters".
- Do not open a popover from inside another popover.

## Closing after an action

Control the popover when a button inside should close it:

```tsx
const [open, setOpen] = React.useState(false)

<Popover open={open} onOpenChange={setOpen}>
  <PopoverTrigger asChild>
    <Button variant="outline">Filters</Button>
  </PopoverTrigger>
  <PopoverContent>
    ...
    <Button onClick={() => { applyFilters(); setOpen(false) }}>Apply filters</Button>
  </PopoverContent>
</Popover>
```

## Styling

The panel reads `--popover` and `--popover-foreground` with a `border` and medium shadow. Change width or padding with `className`; do not pass raw colors.

## Keyboard

| Key | Action |
| --- | --- |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | On the trigger, opens or closes the popover |
| <kbd>Tab</kbd> | Moves through focusable elements inside the popover |
| <kbd>Esc</kbd> | Closes the popover and returns focus to the trigger |

## Focus management

- Opening the popover moves focus to the first focusable element inside, or to the panel itself.
- Closing with <kbd>Esc</kbd> or a click outside returns focus to the trigger.
- Focus is not trapped by default, so <kbd>Tab</kbd> past the last element moves on through the page. Set `modal` if people must stay inside.

## Checklist

- The trigger is a button with a visible label, or an `aria-label` if icon-only. It announces whether the popover is expanded.
- The panel has a visible title so its purpose is clear when focus lands in it.
- Every input inside has a label.
- Nothing important lives only in the popover; people who never open it can still finish their task.
