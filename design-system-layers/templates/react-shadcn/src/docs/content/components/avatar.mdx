## When to use

- To help people recognize who did something: comments, assignees, activity feeds.
- To show who is signed in, usually in the top bar.
- To show a group of people on a shared item.

## When not to use

- **As the only way to identify someone.** Show the name next to the avatar, or in a tooltip in tight spaces.
- **For companies or products.** Use a logo with the right shape; avatars are round and suggest a person.

## Content

- Fallbacks use one or two initials, in capitals: first and last name.
- When there is no name, use a generic person icon rather than a letter that might be wrong.
- Use square, centered photos; the avatar crops them into a circle.

`AvatarBadge`, `AvatarGroup` and `AvatarGroupCount` are styled `span` and `div` elements and accept their native props.

## With an image

```tsx
<Avatar>
  <AvatarImage src={user.imageUrl} alt="" />
  <AvatarFallback delayMs={300}>{initials(user.name)}</AvatarFallback>
</Avatar>
```

## Standalone avatar with a name

When no name is visible nearby, give both the image and the fallback the person's name, so it is read whether or not the image loads:

```tsx
<Avatar>
  <AvatarImage src={user.imageUrl} alt={user.name} />
  <AvatarFallback role="img" aria-label={user.name}>{initials(user.name)}</AvatarFallback>
</Avatar>
```

## Styling

The fallback uses `--muted` and `--muted-foreground`. The badge uses `--primary` with a `--background` ring so it stays visible on any surface.

## Keyboard

Avatars are not interactive. If an avatar opens a profile or menu, wrap it in a link or button, which gets the usual keyboard behavior.

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Moves focus to an avatar wrapped in a link or button |
| <kbd>Enter</kbd> | Opens the profile or menu |

## Checklist

- When the name is shown next to the avatar, the image has `alt=""` so the name is not read twice.
- When the avatar stands alone, it has the person's name as `alt` or `aria-label`.
- An avatar inside a button, like an account menu, gives the button a name such as "Account menu for Jordan Lee".
- Status dots are backed by text; color alone does not say someone is online.
- Group counts have context, for example `aria-label="4 more people"`.
- Fallback initials meet 4.5:1 contrast on `--muted` in light and dark.
