## Principles

- **Use roles, not hex values.** Components ask for `primary` or `muted`, never `#C2410C`. That is what makes dark mode and future brand changes a one-file edit.
- **Every fill has a paired text color.** `primary` goes with `primary-foreground`, `destructive` with `destructive-foreground`. Use the pair together.
- **Generated, not hand-picked.** The palette comes from one seed color through a contrast-aware color model, so every pair is readable.

## Using color in code

```css
.booking-card {
  background: var(--card);
  color: var(--card-foreground);
  border: 1px solid var(--border);
}
```

```tsx
<div className="bg-primary text-primary-foreground">...</div>
```

## Changing the palette

Do not edit theme values by hand. Rerun the generator with a new seed and commit the result:

```bash
scripts/seed-to-tokens.sh --seed "#C2410C" --variant fidelity --shadcn src/theme.css
```

## Accessibility

Text pairs meet WCAG 2.2 AA (4.5:1) and borders, focus rings and form fields meet 3:1 in both themes. Never use color alone to carry meaning: pair it with text or an icon.
