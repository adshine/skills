## The rule: one value

Every corner in the product is derived from a single token, `--radius`, set in `src/brand.css`. The scale below multiplies it:

| Step | Value |
| --- | --- |
| `rounded-sm` | `--radius` x 0.6 |
| `rounded-md` | `--radius` x 0.8 |
| `rounded-lg` | `--radius` |
| `rounded-xl` | `--radius` x 1.4 |
| `rounded-2xl` | `--radius` x 1.8 |
| `rounded-3xl` | `--radius` x 2.2 |
| `rounded-4xl` | `--radius` x 2.6 |
| `rounded-full` | Fully round (pills and circles) |

Change `--radius` and the whole product changes shape together: `0.25rem` reads sharp and technical, `0.625rem` (the default) reads friendly and neutral, `1rem` reads soft. Never set a corner with a fixed value like `rounded-[6px]`; it will not follow when the brand changes.

```css
/* src/brand.css */
:root {
  --radius: 0.625rem;
}
```

## Nesting corners

When one rounded shape sits inside another, the inner radius should be smaller: inner radius is roughly outer radius minus the padding between them. That is why a `rounded-xl` card holds `rounded-md` controls, and a `rounded-md` select holds `rounded-sm` items.

## Round versus pill

Use `rounded-full` for things that are small and self-contained: badges, avatars, toggles and status dots. Keep buttons and inputs on the component default so they line up in forms and toolbars.

## Guidelines

- Use the component default. Only add a radius class when you build a new surface.
- Pick the step by the size of the surface, not by taste.
- Keep one radius per row of controls. A pill button next to a square input looks broken.
- Square corners (`rounded-none`) are for edges that touch another edge, like joined segments in a button group or full-bleed images.
